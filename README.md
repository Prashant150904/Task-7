Objective:

Create a Python script to connect to an SQLite database (sales_data.db), calculate sales metrics (total quantity sold and revenue per product), sort results by revenue, and visualize them using a bar chart.

Tools Used:

Python (with sqlite3, pandas, matplotlib)
SQLite (embedded database)
Jupyter Notebook or .py file

Deliverables:

1.Python Script:
Connects to the SQLite database.
Executes SQL queries to aggregate and sort sales data.
Prints results and generates a sorted bar chart.

2.Sample Database:
Contains a sales table with columns: product, quantity, price.
3.Output Files:
Terminal summary of sales data (sorted by revenue descending).
Bar chart (sales_chart.png) showing revenue by product (sorted).

How to Run:
Clone the repository and navigate to the project folder.
Install dependencies using pip install pandas matplotlib.
Run the script to generate the sorted sales summary and chart.
